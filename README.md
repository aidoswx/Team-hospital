# Damumed — Емханадағы жазылу және медициналық картаны басқару жүйесі
# Орындағандар: Әділ Айдос, Абдусаттар Мұхамеджан

## 1. Жоба туралы

**Damumed** — Java тілінде жасалатын емхана жұмысын басқаруға арналған оқу жобасы.

**Мақсаты:** пациенттерді дәрігерге жазу, электрондық кезекті басқару, медициналық карталарды сақтау және пайдаланушылардың рөлдеріне сәйкес қолжетімділікті ұйымдастыру.

Жүйеде үш негізгі рөл бар: пациент, дәрігер және әкімші.

## 2. Негізгі мүмкіндіктер

- Пациенттер мен дәрігерлерді тіркеу.
- Пайдаланушылардың жүйеге кіруі.
- Дәрігерлердің мамандықтары мен жұмыс кестесін басқару.
- Дәрігер қабылдауына жазылу.
- Бір уақытқа қайталанған жазылуды болдырмау.
- Электрондық кезекті ұйымдастыру.
- Шұғыл пациенттерге басымдық беру.
- Электрондық медициналық картаны жүргізу.
- Қабылдау тарихын сақтау және есептер дайындау.
- Әрекеттерді аудит журналына тіркеу.

## 3. Қолданылған технологиялар

| Технология | Мақсаты |
|---|---|
| Java | Негізгі бағдарламалау тілі |
| OOP | Кластар мен объектілерді ұйымдастыру |
| Collections Framework | Деректерді сақтау және өңдеу |
| PriorityQueue | Электрондық кезекті басқару |
| Comparator | Пациенттердің басымдығын анықтау |

## 4. Жүйенің архитектурасы

Жүйе үш негізгі модульден тұрады:

**1. Пайдаланушылар модулі**

Пациенттерді, дәрігерлерді және әкімшілерді басқарады. Жүйеге кіруді және рөлдерге сәйкес рұқсаттарды тексереді.

**2. Қабылдау және кезек модулі**

Дәрігерлердің жұмыс кестесін сақтайды, қабылдауға жазылуды ұйымдастырады және электрондық кезекті басқарады.

**3. Медициналық карта модулі**

Пациенттің медициналық ақпаратын, диагноздарын және қабылдау тарихын сақтайды.

## 6. Жүйенің жұмыс істеу алгоритмі

1. Пайдаланушы жүйеге логин және құпиясөз арқылы кіреді.
2. Жүйе пайдаланушының рөлін анықтайды.
3. Пациент қажетті дәрігерді және бос уақытты таңдайды.
4. Жүйе таңдалған уақыттың бос екенін тексереді.
5. Бос болса, қабылдауға жазылу жасалады.
6. Пациент электрондық кезекке қосылады.
7. Дәрігер пациентті қабылдайды.
8. Қабылдау нәтижесі медициналық картаға енгізіледі.
9. Орындалған әрекеттер аудит журналына жазылады.

## 7. Пайдаланушылар мен рөлдер

Жүйеде үш рөл қарастырылған:

| Мүмкіндік | Пациент | Дәрігер | Әкімші |
|---|---|---|---|
| Қабылдауға жазылу | ✅ | ❌ | ✅ |
| Өз медициналық картасын көру | ✅ | — | — |
| Рұқсат етілген пациент картасын көру | ❌ | ✅ | — |
| Қабылдау нәтижесін енгізу | ❌ | ✅ | ❌ |
| Дәрігер кестесін басқару | ❌ | — | ✅ |
| Пайдаланушыларды басқару | ❌ | ❌ | ✅ |
| Жүйелік есептерді қарау | ❌ | — | ✅ |

**Ескерту:** медициналық деректерге қолжетімділік пайдаланушының рөлімен ғана емес, нақты пациентке қатысты рұқсатымен де шектеледі.

## 8. Электрондық кезек жүйесі

Электрондық кезек `PriorityQueue` және `Comparator` көмегімен ұйымдастырылады.

Пациенттер екі санатқа бөлінеді:

- **Шұғыл пациент** — жоғары басымдық.
- **Қарапайым пациент** — стандартты басымдық.

`Comparator` пациенттерді басымдық деңгейі бойынша сұрыптайды. Басымдығы бірдей пациенттер тіркелу уақыты бойынша реттеледі.

**Мысал:**

| Пациент | Санаты | Кезектегі орны |
|---|---|---|
| Айдос | Шұғыл | 1 |
| Мұхамеджан | Қарапайым | 2 |
| Әділ | Қарапайым | 3 |

Егер шұғыл пациент келсе, ол кезекте жоғары басымдыққа ие болады.

**Қосымша шарт:** бір дәрігерге бір уақыт аралығында екі пациентті қатар жазуға болмайды. Жүйе уақыттардың қабаттасуын тексеруі тиіс.

## 9. Медициналық карта

`MedicalRecord` класы пациенттің медициналық ақпаратын сақтауға арналған.

**Негізгі деректер:**

- Пациенттің аты-жөні және идентификаторы.
- Қабылдау күні.
- Қабылдаған дәрігер.
- Диагноз.
- Тағайындалған ем.
- Қабылдау тарихы.

Дәрігер қабылдау аяқталғаннан кейін медициналық картаға жаңа ақпарат енгізеді.

Пациент өзінің медициналық тарихын қарай алады.

## 10. Қауіпсіздік және аудит

Жүйенің қауіпсіздігі үш негізгі механизмге негізделеді.

**1. Құпиясөздерді қорғау**

Құпиясөздер ашық мәтін түрінде сақталмайды. Оларды сақтау үшін арнайы құпиясөз хештеу алгоритмі қолданылады.

**2. Рөлдер бойынша қолжетімділік**

Әр пайдаланушы тек өз рөліне және берілген рұқсаттарына сәйкес әрекеттерді орындай алады.

**3. Аудит журналы**

`AuditLogger` жүйеде орындалған әрекеттерді файлға жазады.

Мысалы:

```text
2026-11-06 09:00 | LOGIN | patient_01
2026-11-06 09:05 | APPOINTMENT_CREATED | patient_01
2026-11-06 09:30 | RECORD_UPDATED | doctor_02
```

Аудит журналы жүйедегі әрекеттерді бақылауға және қателерді анықтауға көмектеседі. Медициналық деректердің толық мазмұны журналға жазылмайды.

## 11. Бағдарламаны іске қосу

**Қажетті құралдар:**

- Java JDK 17 немесе одан жоғары.
- IntelliJ IDEA немесе басқа Java IDE.
- Git.

**Іске қосу қадамдары:**

1. GitHub репозиторийін компьютерге жүктеу.
2. Жобаны IntelliJ IDEA арқылы ашу.
3. Java SDK нұсқасын тексеру.
4. Жобаның негізгі `Main` класын іске қосу.
5. Жүйеге қажетті рөлмен кіру.

*Нақты іске қосу командасы жобаның құрылымына байланысты анықталады.*

## 12. Жобаның артықшылықтары мен кемшіліктері

**Артықшылықтары:**

- Емхана жұмысын автоматтандыру.
- Пациенттердің уақытын үнемдеу.
- Қабылдауға қайталанған жазылуды болдырмау.
- Шұғыл пациенттерге басымдық беру.
- Медициналық ақпаратты жүйелі сақтау.
- Рөлдер арқылы қолжетімділікті шектеу.

**Кемшіліктері:**

- Электрондық кезекті басқару логикасының күрделілігі.
- Пациенттердің жеке деректерін қорғауға жоғары талап қойылуы.
- Бірнеше пайдаланушы қатар жұмыс істегенде синхрондаудың қажеттілігі.
- Жүйенің тұрақты жұмыс істеуі үшін деректерді сенімді сақтау қажеттілігі.

## 13. Болашақта дамыту мүмкіндіктері

- PostgreSQL деректер қорын қосу.
- Spring Boot көмегімен REST API жасау.
- Веб-интерфейс әзірлеу.
- SMS және электрондық пошта арқылы хабарландыру.
- Дәрігерлердің бос уақытын автоматты түрде ұсыну.
- Медициналық есептерді PDF форматында шығару.
- Қабылдау статистикасын визуализациялау.
- Резервтік көшіру және деректерді шифрлау.

## 14. Қорытынды

**Damumed** — емханадағы пациенттерді тіркеу, дәрігер қабылдауына жазылу, электрондық кезек пен медициналық карталарды басқаруға арналған Java оқу жобасы.

Жоба OOP принциптерін, Java Collections Framework, `PriorityQueue`, `Comparator`, файлмен жұмыс істеу және рөлдер бойынша қолжетімділікті басқару механизмдерін тәжірибеде қолдануға бағытталған.
