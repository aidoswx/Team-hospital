# Damumed — емхана сервисі

## Авторлар: Әділ Айдос, Абдусаттар Мұхамеджан.
## 1. Жобаның сипаттамасы
Damumed — емхана жұмысын автоматтандыруға арналған ақпараттық жүйе. Жүйе пациенттерге дәрігер қабылдауына онлайн жазылуға, электрондық кезекті пайдалануға және жеке медициналық картасын көруге мүмкіндік береді.
Сонымен қатар дәрігерлер өз қабылдау кестесін басқарып, пациенттердің медициналық тарихымен жұмыс істей алады. Әкімші жүйедегі пайдаланушыларды, дәрігерлерді және жалпы процестерді бақылайды.
